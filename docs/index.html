Production & Organization-Level Architecture

Engineered to solve real-world edge latency, memory drift, and enterprise confidentiality.

🎙️ Dual-Stream Edge ASR

Separates your microphone (RealtimeSTT dual-VAD sub-100ms streaming) from remote attendees (WASAPI Loopback + faster-whisper INT8). Uses a 400ms acoustic boundary overlap and N-gram deduplication so fast speakers never lose boundary words.

🧠 Bi-Temporal Knowledge Graph

Tracks technical decisions with chronological state decay (ACTIVE vs SUPERSEDED). When a new architecture choice overrides an older one, the graph preserves lineage so RAG never surfaces stale truth.

⚡ Zero-Click Local Vector RAG

Embeds decisions using BAAI/bge-small-en-v1.5 (384-d ONNX via fastembed). Detects spoken questions in real time and surfaces context flashcards in <10ms without touching the keyboard.

🛡️ Zero-Trust Vault & Stealth HUD

Transcripts are encrypted at rest via Windows DPAPI + AES-256-GCM in SQLite WAL mode. The PySide6 HUD enforces Win32 WDA_EXCLUDEFROMCAPTURE so it stays 100% invisible on Zoom/Teams/OBS screen shares.

Engineering Trade-offs: Modern Edge AI vs. Old-School Tech

Key architectural decisions made to eliminate latency, hallucination, and privacy leaks.

⚡ Dual-Stream + 400ms Overlap vs. Naive VAD Chunking

Old-School: Hard-chopping audio at fixed 2s intervals with Silero VAD drops unstressed words on fast speakers.
DevListen: Dual-stream separation (YOU vs ATTENDEES) + 400ms acoustic boundary overlap & N-gram deduplication preserves 100% of boundary syllables.

🕒 Bi-Temporal Graph vs. Flat Vector RAG

Old-School: Flat vector DBs retrieve deprecated decisions alongside current ones, causing contradictions.
DevListen: Models ACTIVE vs SUPERSEDED state lineage so RAG always surfaces current architectural truth.

🔐 Local ONNX + INT8 vs. Cloud APIs

Old-School: Streaming corporate audio to external APIs creates compliance risk and 600ms+ network jitter.
DevListen: Runs faster-whisper INT8 + BGE-Small ONNX locally in <190ms with zero bytes leaving the device.
