Why DevListen? The Problem It Solves

Existing cloud meeting bots leak confidential audio, clutter calls, and retrieve outdated decisions. DevListen fixes all four at the edge.

🧠 Decision Drift & Stale RAG

Problem: Flat vector RAG surfaces deprecated decisions alongside current ones.
Solution: A Bi-Temporal Knowledge Graph (ACTIVE vs SUPERSEDED) that drafts natural spoken replies grounded only in current truth.

🔒 Enterprise NDA & Cloud Leaks

Problem: Cloud SaaS bots send sensitive engineering & client audio to external servers.
Solution: 100% Offline Edge AI (INT8 Whisper + ONNX RAG + DPAPI/AES-256-GCM) with zero bytes leaving your laptop.

👻 Intrusive Bots & Screen-Share Exposure

Problem: Meeting bots interrupt calls, and normal overlays show up on screen shares.
Solution: Passive OS-level capture (zero bots) + Win32 WDA_EXCLUDEFROMCAPTURE hardware invisibility.

⚡ Fast-Speech Word Clipping

Problem: Naive local STT hard-chops buffers and drops rapid syllables.
Solution: 400ms acoustic boundary overlap + N-gram deduplication preserves every word on CPU.

Layered System Architecture & Data Flow

5 decoupled layers engineered for low CPU overhead, deterministic concurrency, and zero stale context in RAG.

L1 • OS Audio Ingestion
WASAPI Loopback (48kHz) + Mic (44.1kHz) ➔ Polyphase Sinc Resampling (16kHz Mono PCM) ➔ Energy / WebRTC VAD Gate ➔ Lock-free AudioRingBuffer. Isolates your mic from remote audio at the OS driver level.
L2 • Edge Streaming ASR
Dual-Engine Inference: RealtimeSTT (tiny+base, sub-100ms mic) + faster-whisper (CTranslate2 INT8 CPU, 400ms trailing overlap, vad_filter=False) ➔ ConversationalTurnAggregator (1–5 word N-gram deduplication).
L3 • Cognitive GraphRAG
Autonomous Extractors + Bi-Temporal Graph: DecisionExtractor, CommitmentExtractor & QuestionDetector ➔ TemporalDecisionGraph (ACTIVE vs SUPERSEDED lineage) + BAAI/bge-small-en-v1.5 (384-d ONNX cosine search in <10ms).
L4 • Zero-Trust Vault
Encrypted Persistence: Windows DPAPI master key sealing + AES-256-GCM payload encryption stored in SQLite WAL mode + 1-click Markdown ADR Exporter. Zero bytes leave the device.
L5 • Stealth Presentation
DevListen Studio (PySide6): Hardware-excluded overlay via Win32 WDA_EXCLUDEFROMCAPTURE (0x11), real-time QPainter waveform, and natural spoken-reply synthesis.

🎙️ Dual-Stream + 400ms Overlap

Separating Mic (YOU) from Loopback (ATTENDEES) eliminates echo and self-diarization drift. Keeping a 400ms trailing audio overlap with vad_filter=False ensures rapid speakers never lose boundary syllables.

🕒 Bi-Temporal Graph vs. Flat RAG

Flat vector DBs surface deprecated decisions alongside current ones. Modeling ACTIVE vs SUPERSEDED state lineage guarantees RAG retrieves only current architectural truth in <10ms.

⚡ Quantized INT8 + ONNX CPU

Runs faster-whisper (CTranslate2 INT8) and BAAI/bge-small-en-v1.5 (ONNX) locally without a datacenter GPU—delivering <190ms ASR latency and 0 bytes sent to external APIs.
